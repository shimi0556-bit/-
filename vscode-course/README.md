# קורס VS Code — אינטראקטיבי

קורס עברי (RTL), אינטראקטיבי ועצמאי, על Visual Studio Code — מקובץ HTML יחיד, בלי build ובלי תלות ברשת.

## איך מריצים

פותחים את `index.html` ישירות בדפדפן (double-click, או `open index.html` / `start index.html`).

## מה בפנים

- **3 שלבים ברצף אחד**: מתחילים (7 שיעורים) → בינוני (7 שיעורים) → מקצוענים (8 שיעורים) — 22 שיעורים בסך הכול.
- כל שיעור: תוכן ממוקד, טיפ מעשי, ושאלת תרגול עם משוב מיידי והסבר.
- מעקב התקדמות שנשמר ב-`localStorage` בין ביקורים (מפתחות עם prefix `vscode_course_`).
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל 22 השאלות (סף מעבר: 80%).
- תעודת סיום אישית (נפתחת רק אחרי השלמת כל השיעורים), ניתנת להדפסה/שמירה כ-PDF.

נבנה עם סקיל `interactive-course-builder`.
