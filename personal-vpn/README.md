# VPN פרטי משלך (WireGuard)

VPN שרץ על **שרת שלך**, לא על שרת של חברת VPN. סקריפט אחד מתקין אותו, ואחר כך מוסיפים טלפון או מחשב בסריקת קוד QR.

## מה ההבדל מאפליקציית VPN רגילה

| | אפליקציית VPN רגילה (NordVPN, Proton, תוסף לדפדפן...) | ה-VPN הזה |
|---|---|---|
| מי רואה את התעבורה שלך | החברה | רק השרת שלך |
| כתובת IP | משותפת לאלפי משתמשים, הרבה אתרים חוסמים אותה או מציגים CAPTCHA | כתובת IP שמשמשת רק אותך |
| מחיר | בדרך כלל מנוי חודשי | מחיר של שרת קטן, בערך 4–6 דולר לחודש (יש גם חינמי, ראה למטה) |
| מכשירים | לפי המנוי | כמה שרוצים (עד 253) |
| חסימת פרסומות | לפעמים, בתשלום נוסף | אופציונלי, בחינם (AdGuard DNS) |
| פרוטוקול | משתנה | WireGuard: מהיר, מודרני, חסכוני בסוללה |

## מה צריך

1. **שרת (VPS) עם Ubuntu 22.04 או 24.04** (אפשר גם Ubuntu 20.04 או Debian 11 ומעלה). המדינה שבה נמצא השרת היא המדינה שממנה הגלישה שלך תיראה באינטרנט. כמה אפשרויות:
   - **Hetzner**: גרמניה, פינלנד, ארה"ב. זול ופשוט, בלי חומת אש שצריך לפתוח.
   - **Vultr** או **DigitalOcean**: הרבה מיקומים בעולם (ב-Vultr יש גם תל אביב).
   - **Oracle Cloud Free Tier**: חינם, אבל ההרשמה מסובכת יותר וצריך לפתוח פורט בחומת האש שלהם (ראה "פתרון בעיות").

   את המחיר העדכני כדאי לבדוק באתר של הספק.
2. **אפליקציית WireGuard** (חינמית) בכל מכשיר: [iPhone/iPad](https://apps.apple.com/app/wireguard/id1441195209) · [Android](https://play.google.com/store/apps/details?id=com.wireguard.android) · [Windows / Mac](https://www.wireguard.com/install/)

## התקנה (פעם אחת, בערך 2 דקות)

**1. מתחברים לשרת.** אחרי שקונים שרת, הספק נותן כתובת IP וסיסמה או מפתח. ב-Windows פותחים PowerShell, ובמק פותחים Terminal, ומקלידים (עם הכתובת שלך):

```bash
ssh root@1.2.3.4
```

**2. מורידים ומריצים את הסקריפט:**

```bash
curl -fsSLO https://raw.githubusercontent.com/shimi0556-bit/-/main/personal-vpn/vpn.sh
sudo bash vpn.sh
```

**3. עונים על השאלות.** בכל שאלה אפשר פשוט ללחוץ Enter:
- כתובת השרת והפורט מזוהים לבד.
- DNS: `1` Cloudflare (הכי מהיר), `2` AdGuard (**חוסם פרסומות**), `3` Quad9 (חוסם אתרים זדוניים), `4` Google.
- שם למכשיר הראשון, **באנגלית** (למשל `phone`).

**4. מחברים את הטלפון.** על המסך יופיע קוד QR. באפליקציית WireGuard לוחצים על **+** ואז **Create from QR code** (באייפון) או **Scan from QR code** (באנדרואיד), סורקים ומפעילים.

**במחשב:** באפליקציית WireGuard בוחרים **Add empty tunnel**, מוחקים את מה שכתוב שם ומדביקים את הטקסט שהסקריפט הדפיס בין שני הקווים.

לבדיקה: נכנסים ל-[whatismyipaddress.com](https://whatismyipaddress.com) ומוודאים שמופיעה כתובת ה-IP של השרת.

## שימוש יומיומי

אחרי ההתקנה, בכל כניסה לשרת פשוט מקלידים `sudo vpn` ומקבלים תפריט. או ישירות:

| פקודה | מה היא עושה |
|---|---|
| `sudo vpn` | תפריט: הוספה, הצגה, הסרה |
| `sudo vpn add laptop` | מוסיף מכשיר חדש בשם laptop ומציג QR |
| `sudo vpn show phone` | מציג שוב את ה-QR של phone |
| `sudo vpn list` | רשימת מכשירים, מתי כל אחד התחבר לאחרונה וכמה הוריד |
| `sudo vpn remove phone` | מנתק מכשיר לתמיד (למשל טלפון שאבד) |
| `sudo vpn uninstall` | מוחק את ה-VPN מהשרת |

לכל מכשיר כדאי ליצור קובץ נפרד (`phone`, `laptop`, `mom-ipad`). ככה אם מכשיר אחד אובד, מסירים רק אותו.

## פתרון בעיות

- **הטלפון לא מתחבר, ובאפליקציה רואים "Sent" אבל לא "Received":** לספק השרת יש חומת אש משלו. צריך לפתוח בה את הפורט שהסקריפט הציג (**UDP**):
  - Oracle Cloud: ב-VCN, תחת Security List, מוסיפים Ingress Rule עם UDP והפורט.
  - AWS: ב-Security Group, תחת Inbound rules, מוסיפים Custom UDP.
  - Google Cloud: ב-VPC network, תחת Firewall.
  - Azure: ב-Network security group.
  - ב-Hetzner, DigitalOcean ו-Vultr אין צורך בזה, אלא אם הוספת חומת אש בעצמך.
- **ברשת מסוימת (עבודה, מלון) לא מתחבר:** יש רשתות שחוסמות פורטים לא מוכרים. אפשר להתקין מחדש עם פורט 443: `sudo vpn uninstall`, ואז `sudo bash vpn.sh` ובשאלת הפורט מקלידים `443`.
- **חלק מהאתרים לא נטענים ברשת סלולרית:** באפליקציה עורכים את החיבור (Edit) ומוסיפים תחת `[Interface]` את השורה `MTU = 1280`.
- **האם זה עובד?** `sudo vpn list`: בעמודה LAST SEEN צריך להופיע משהו כמו `12s ago`.

## אבטחה

- כל מכשיר מקבל מפתח משלו, ויש גם מפתח משותף נוסף (PresharedKey) לשכבת הגנה נוספת.
- מכשירים ב-VPN **לא יכולים לראות זה את זה**. הם יכולים רק לצאת לאינטרנט דרך השרת, כך שקובץ שדלף לא יאפשר גישה למכשירים האחרים שלך.
- אם לשרת אין IPv6, תעבורת IPv6 של המכשיר נחסמת בתוך המנהרה ולא "בורחת" מחוץ ל-VPN.
- קובצי המכשירים שמורים בשרת ב-`/etc/wireguard/wgvpn0-clients/` וזמינים רק למשתמש root. **כל מי שיש לו קובץ או QR יכול להשתמש ב-VPN שלך**, אז לא שולחים אותם לאף אחד.
- מעדכנים את השרת מדי פעם: `sudo apt update && sudo apt upgrade`.
- ה-VPN נקרא `wgvpn0` ומשתמש ברשת `10.66.66.0/24`, כדי שלא יתנגש עם VPN אחר שכבר מותקן על אותו שרת.

## מה הסקריפט עושה בפועל

1. מתקין את `wireguard-tools`, `qrencode` ו-`iptables` (רק מה שחסר).
2. יוצר מפתחות לשרת ואת `/etc/wireguard/wgvpn0.conf`, עם כללי NAT וחומת אש שנוספים כשה-VPN עולה ונמחקים כשהוא יורד.
3. מפעיל העברת תעבורה (IP forwarding) ואת השירות `wg-quick@wgvpn0`, כך שה-VPN עולה מחדש גם אחרי אתחול השרת.
4. מעתיק את עצמו ל-`/usr/local/bin/vpn` כדי שבפעם הבאה יספיק להקליד `sudo vpn`.

התקנה בלי שאלות (לאוטומציה):

```bash
VPN_AUTO=1 VPN_PORT=51820 VPN_DNS=adguard VPN_FIRST_CLIENT=phone sudo -E bash vpn.sh install
```

## בדיקות

`tests/e2e-netns.sh` בונה על מחשב Linux אחד שלושה "מחשבים" וירטואליים (לקוח, שרת VPN ו"אינטרנט"), מתקין את ה-VPN ובודק שהלקוח מגיע לאינטרנט רק דרך המנהרה. הוא גם בודק הוספה, הסרה, מכשיר שהוסר שכבר לא מצליח להתחבר, והסרת ההתקנה. מריצים אותו רק על מכונה זמנית, כי הוא כותב ל-`/etc/wireguard`:

```bash
sudo bash tests/e2e-netns.sh
```
