# קורס Canva מלא — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת. אותה תבנית קורס כמו [`../powerpoint-course/`](../powerpoint-course), [`../excel-course/`](../excel-course), [`../gmail-course/`](../gmail-course) ו-[`../windows-desktop-course/`](../windows-desktop-course), בנוי דרך הסקיל [`interactive-course-builder`](../claude-skills/interactive-course-builder).

## מה יש בפנים

- **3 שלבים · 22 שיעורים**: מתחילים (ממשק, יצירת עיצוב, טקסט, תמונות, אלמנטים גרפיים, שכבות, שמירה/הורדה) → בינוני (Brand Kit, עמודים מרובים, אנימציות, Grids, עריכת תמונות, תבניות/Magic Resize, שיתוף פעולה) → מקצוענים (קיצורי מקלדת, Canva Pro, כלי Magic Studio/AI, עריכת וידאו, תבניות עסקיות, Content Planner, ייצוא מתקדם, עקרונות עיצוב + השוואה ל-Adobe Express ול-PowerPoint).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר.
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.
- לחיצה אחת על "אחורה" בדפדפן יוצאת מהקורס לגמרי (לא מדפדפת בין שיעורים פנימיים).

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open canva-course/index.html   # macOS
xdg-open canva-course/index.html   # Linux
```
