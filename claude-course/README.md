# קורס Claude מלא — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת. אותה תבנית קורס כמו [`../powerpoint-course/`](../powerpoint-course), [`../excel-course/`](../excel-course), [`../gmail-course/`](../gmail-course), [`../windows-desktop-course/`](../windows-desktop-course), [`../canva-course/`](../canva-course), [`../vscode-course/`](../vscode-course) ו-[`../obsidian-course/`](../obsidian-course), בנוי דרך הסקיל [`interactive-course-builder`](../claude-skills/interactive-course-builder).

## מה יש בפנים

- **3 שלבים · 22 שיעורים**: מתחילים (claude.ai, פרומפטים, קבצים, היסטוריית שיחות, Artifacts, אפליקציות, פרטיות ומגבלות) → בינוני (Projects, Styles, בחירת מודל Opus/Sonnet/Haiku, חיפוש אינטרנט, Extended thinking, Connectors, פרומפטים מתקדמים, שיתוף) → מקצוענים (Claude Code, Claude API, Tool use, MCP, חלון הקשר ו-Prompt caching, Constitutional AI ופרטיות, קיצורים, השוואה ל-ChatGPT/Gemini).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר (סף מעבר 80%).
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.
- לחיצה אחת על "אחורה" בדפדפן יוצאת מהקורס לגמרי (לא מדפדפת בין שיעורים פנימיים).

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open claude-course/index.html   # macOS
xdg-open claude-course/index.html   # Linux
```
