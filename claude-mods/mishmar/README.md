# משמר (mishmar): מוד ל-Claude Code

מוד (תוסף חי של function hooks) שנותן לוח בקרה בעברית לסשן, ושומר שחוסם פעולות מסוכנות לפני שהן רצות.

## מה הוא עושה

### לוח הבקרה
- **שורת סטטוס** מתחת לשורת הכתיבה: `🛡️ משמר פעיל · ⛔ 1 · ⚠️ 2`.
- **פס מעל שורת הכתיבה** (בטרמינל ובדסקטופ): כמה זמן הסשן רץ, כמה כלים רצו, כמה קבצים נערכו, ומונה חסימות. יש בו כפתור `[לוח]` שפותח את הפאנל (מקש `l`) וכפתור `[הסתר]`. הפס מופיע רק אחרי שמשהו קרה.
- **פאנל "משמר"**: גרף עמודות של הכלים, רשימת הקבצים שנערכו (וכמה פעמים), החסימות והאזהרות האחרונות עם הסיבה, ומספר התורות וזמן התור האחרון. בפאנל יש כפתורים לכיבוי והפעלה של השומר (`g`), איפוס (`r`) וסגירה.

### יומן פעולות וסרגל צדדי
- **הסביבה:** בכל טעינה המוד בודק איפה הסשן רץ: ענן (Claude Code באתר או באפליקציה, כולל סוג הסביבה) או מחשב מקומי, וגם את הריפו, הענף, התיקייה, הגרסה והקישור לסשן.
- **יומן:** כל גישה ל-GitHub (כלי ה-MCP של GitHub, ‏`git push/pull/fetch/clone`, ‏`gh`) מסומנת "כתיבה" כשהיא משנה משהו בשרת. נרשמים גם קומיטים ושאר פעולות git מקומיות, כל שימוש בסקיל, כל קריאה לתוסף או לקונקטור (כלי `mcp__…`), סוכנים שהופעלו, ופקודות `/` שהמשתמש מריץ. היומן מופיע בפאנל וב-`/mishmar`.
- **סרגל צדדי חי:** אפליקציית Claude לא מציירת ממשק של מודים, ולכן היומן נשלח גם לדף Artifact (`sidebar/index.html`) עם מסד נתונים חי. הדף מתעדכן כל שתי שניות ואפשר להשאיר אותו פתוח בצד. כתובת הדף נשמרת ב-`~/.claude/mishmar.json`:

  ```json
  { "sidebarUrl": "https://claude.ai/artifact/…" }
  ```

  הכתיבה נעשית דרך הכלי ArtifactData. אם היא נכשלת, המוד מפסיק לשלוח ומודיע על כך. `/mishmar sidebar` מנסה שוב.

### השומר
| רמה | מה נתפס |
|---|---|
| ⛔ חסימה | מחיקה רקורסיבית (`rm -r`/`-rf`, `find -delete`) של `/`, `~`, `$HOME`, `*`, `.`, `..`, `.git` או תיקיות מערכת; `--no-preserve-root`; `git push --force` / `-f` / `+ref` / `--mirror`; `mkfs`, `wipefs`, `dd`/`shred`/הפניה לדיסק; fork bomb; `chmod`/`chown -R` על תיקייה קריטית |
| ⛔ חסימה (עריכת קבצים) | `.env` (חוץ מ-`.env.example` ודומיו), `*.pem`/`*.key`/`*.p12`, מפתחות SSH פרטיים, `~/.ssh/`, `~/.aws/credentials`, `.netrc`, `~/.docker/config.json`, ותיקיית `.git/` הפנימית |
| ⚠️ אזהרה (עובר, עם הודעה) | `git reset --hard`, `git clean -f`, `git branch -D`, `git push --delete`, `filter-branch`, `curl … \| sh`, `chmod -R 777`, `DROP`/`TRUNCATE` במסד נתונים |

`git push --force-with-lease` מותר. הבדיקה מבינה גרשיים, `&&`/`;`/`|`, ‏`$( )`, ‏`bash -c "…"`, ‏`eval`, ‏`sudo` ו-here-docs, כך שלמשל `echo "rm -rf /"` לא נחסם. זו הגנה מפני תאונות נפוצות, לא חומת אבטחה מול מי שמנסה לעקוף אותה בכוונה.

כשמשהו נחסם, Claude מקבל הסבר בעברית ומתבקש לא לעקוף את החסימה, אלא לבקש מהמשתמש לבצע את הפעולה בעצמו או לכבות את השומר.

## פקודות

| פקודה | פעולה |
|---|---|
| `/mishmar` | פותח את הפאנל ומדפיס סיכום |
| `/mishmar off` (או `כבה`) | מכבה את השומר לסשן הנוכחי. עובד רק כשהמשתמש מקליד את הפקודה: אם Claude או תוסף אחר מנסים להריץ אותה, היא נדחית |
| `/mishmar on` (או `הפעל`) | מפעיל את השומר מחדש |
| `/mishmar reset` (או `אפס`) | מאפס את הסטטיסטיקה |
| `/mishmar sidebar` (או `סרגל`) | מציג את הקישור לסרגל הצדדי ומנסה שוב אם השליחה נעצרה |
| `/mishmar help` (או `עזרה`) | עזרה |

השומר נדלק מחדש בכל סשן חדש, גם אם כובה קודם.

## התקנה

לסשן אחד:

```bash
claude --plugin-dir /path/to/-/claude-mods/mishmar
```

כדי שייטען בכל סשן (גם באפליקציית הדסקטופ), הוסף את הנתיב ל-`env` ב-`~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/-/claude-mods/mishmar" } }
```

## פיתוח

```bash
claude plugin validate claude-mods/mishmar   # בודק את המניפסט ואת המודול
claude plugin test claude-mods/mishmar       # 17 בדיקות: השומר, היומן, הסרגל, הפקודה, הפאנל והפס
```

בכל טעינה המנוע מניח הגדרות טיפוסים לעורך הקוד ב-`.claude-plugin/types/`. התיקייה הזו לא נשמרת ב-git.

| קובץ | תפקיד |
|---|---|
| `.claude-plugin/plugin.json` | המניפסט |
| `hooks/hooks.json` | מצביע על המודול |
| `hooks/register.tsx` | ה-hooks: ספירה, שומר, יומן, סנכרון לסרגל, פקודה, פאנל ופס. כל מה שנוגע ב-`$` חייב להיות בקובץ הזה |
| `hooks/guard.ts` | חוקי השומר (lexer קטן ל-shell ובדיקת נתיבים), בלי תלות במנוע |
| `hooks/activity.ts` | מה נכנס ליומן: GitHub, git, סקילים, תוספים, סוכנים |
| `hooks/sidebar.ts` | עזרים לסרגל הצדדי (כתובת, ריפו, גרסה), בלי תלות במנוע |
| `sidebar/index.html` | דף הסרגל הצדדי (Artifact עם מסד נתונים חי) |
| `types/index.d.ts` | החוזה של `$.state` (stats, isGuardOn, isBandHidden) |
| `tests/mishmar.test.ts` | הבדיקות |
