# Cartoon News Creator

## Instructions

### Step 1: Identify the News Topic and Angle

Ask the user (or extract from their prompt) the following:

| Field | Description | Example |
|-------|-------------|---------|
| Topic | The news story or current event | Israeli budget crisis, Gaza ceasefire talks |
| Angle | The satirical point being made | Government hypocrisy, media spin, broken promises |
| Target | Who or what is being satirized | A specific politician, an institution, a trend |
| Tone | How sharp the satire should be | Gentle irony, biting sarcasm, absurdist humor |
| Language | Hebrew caption or English caption | Hebrew (default for Israeli topics) |

If the user provides a headline or news snippet, extract the angle yourself and propose it for confirmation before proceeding.

### Step 2: Choose a Visual Metaphor

Select one or more classic cartoon metaphors suited to the story. Use this decision matrix:

| Situation | Recommended Metaphor |
|-----------|---------------------|
| Politicians making promises | Hot air balloons that pop |
| Government overspending | A figure drowning in coins or receipts |
| Coalition instability | A rickety chair with broken legs |
| Media bias | A funhouse mirror or crooked lens |
| International negotiations | Two figures arm-wrestling over a table |
| Bureaucratic delay | A figure buried under stacks of papers |
| Economic inequality | A seesaw with very unequal weights |
| Election campaigns | Circus performers, clowns, tightrope walkers |
| Military or security tension | Chess pieces, a pressure cooker |
| Environmental neglect | A wilting tree, rising floodwaters |

If the user's topic does not match a row, propose the closest metaphor and explain the mapping.

### Step 3: Draft the Visual Scene Description

Write a structured scene description with these components:

1. **Setting**: Where does the scene take place? (Knesset chamber, a living room with a TV, a Middle East map backdrop, a bank vault)
2. **Characters**: Who appears, and how are they depicted? (exaggerated physical traits of a public figure, a generic "citizen" figure, symbolic animals)
3. **Action**: What is happening in the scene?
4. **Props and symbols**: What objects carry meaning? (Israeli flag, NIS coins, a ballot box, a newspaper headline in the background)
5. **Caption or speech bubble**: The punchline, in Hebrew or English as requested.
6. **Style note**: Sketch style, ink-heavy editorial style, colorful caricature, minimalist line art.

### Step 4: Write the Caption

Craft 2-3 caption or speech-bubble options. Each should:

- Be short (under 10 words for a caption, under 20 for a speech bubble).
- Carry the satirical punch on its own, the image supports it.
- Use wordplay, irony, or a reversal when possible.
- Be in the requested language (Hebrew default for Israeli audience).

Hebrew caption template (indented block, not a code fence):

    "בסוף, כולנו שווים בפני התקציב."
    "הבטחתי. הבטחתי מאוד."
    "הרפורמה בדרך, רק עוד כמה עשורים."

English caption template:

    "Transparency at last: you can see right through it."
    "The coalition stands firm. For now."
    "Budget approved. Citizens not included."

### Step 5: Provide an Image-Generation Prompt

Write a ready-to-use prompt the user can paste into an image generator such as Midjourney, DALL-E 3, Adobe Firefly, or Stable Diffusion.

Format:

    Editorial cartoon style, black ink with flat color washes,
    [scene description in English],
    [character description],
    [props],
    speech bubble reading "[caption in English or transliterated Hebrew]",
    satirical, exaggerated proportions, newspaper illustration aesthetic.

Always write the image-generation prompt in English, even if the caption is Hebrew, because most image generators do not reliably render Hebrew text in images.

In an environment with direct image-generation tools available (see Step 7), still produce this portable prompt — it's the deliverable when the user wants to paste it elsewhere themselves, and it's also exactly the `prompt` argument those tools need.

### Step 6: Optional Variants

Offer the user 2 alternative takes on the same topic:

- **Variant A**: A softer, more ironic version (suitable for mainstream media).
- **Variant B**: A sharper, more confrontational version (suitable for an opinion blog or social media).

Each variant gets its own scene description, caption, and image-generation prompt.

### Step 7: Generate the Image Directly (when available)

Don't stop at handing the user a portable prompt if this environment has direct image-generation tools connected — offer to generate the cartoon on the spot instead of making the user paste it into an external service themselves. Two MCP-based generators are commonly available:

- **ElevenLabs `creative_generate_image`** — the more capable option for this skill's needs. Pass the Step 5 prompt as `prompt`. Model choice matters here:
  - **`gpt-image-2`** — pick this when the caption/speech-bubble text should be rendered legibly *inside* the image itself (it's the model this tool's own guidance names for rendered text, infographics, and multi-panel layouts). Use it for an **English** caption baked into the speech bubble.
  - **`gemini-2.5-flash-image`** (the tool's default) — fine for the illustration when the caption will be added separately instead of rendered in-image (the usual path for a **Hebrew** caption — see the Gotcha below, which still applies: generate the scene with no in-image text, then overlay the Hebrew caption in post).
  - It generates 4 variations by default, which maps neatly onto offering the user a choice, or onto the two variants from Step 6 plus alternates.
  - It spends credits per call — use `estimate_only` first if the user should approve the spend, and never call it twice to "retry" the same generation (that's a second billed run).
- **Gamma `generate_image`** — simpler and faster for a single illustration, with an explicit `sizePreset` for the target format (`social-square` for a feed post, `story` for a 9:16 share, `banner`/`slide` for 16:9). Set `type: "illustration"` or `"scene"` for the editorial-cartoon look; it does not reliably render in-image text either, so treat it the same as `gemini-2.5-flash-image` above for caption handling.

Either way, still produce the portable English prompt from Step 5 first — it's both the user-facing deliverable and the direct input to whichever generator is used.

## Gotchas

- Image generators do not reliably render Hebrew text inside images — this includes the direct generators in Step 7. Always write the image-generation prompt in English and treat the Hebrew caption as a label to be added in post-production (Canva, Photoshop, or manually by an illustrator) rather than asking any generator, including `gpt-image-2`, to render it in-image.
- Caricature of a real, named public figure is legally protected satire in most democracies, including Israel, but must be clearly satirical and not defamatory. Do not present satire as factual reporting. Add a visible "קריקטורה" or "Satire" label when ambiguity risk is high.
- Avoid cartoons that rely solely on a person's physical appearance as the punchline. The humor should come from the political or social irony, not from mocking appearance.
- Mixed Hebrew and Latin text in the same caption can render in unexpected visual order due to BiDi (bidirectional) rules. If the caption mixes Hebrew and English brand names or numbers, test rendering before publishing.
- Israeli humor tends toward cynical self-deprecation ("tzabar humor") rather than gentle whimsy. Calibrate tone accordingly when the audience is Israeli.
- Gershayim ("״") are used for Hebrew abbreviations (כנה"ץ, מע"מ). Preserve them if quoting official acronyms in captions; do not replace with straight double-quotes.

## Troubleshooting

### Problem: The image-generation prompt produces a generic illustration, not a cartoon

Cause: The prompt lacks style-specific keywords that image generators respond to.
Solution: Prepend "editorial cartoon, newspaper caricature, ink line art, flat color washes, exaggerated proportions" to the prompt. Midjourney responds well to adding "--style expressive" or "--sref [a reference editorial cartoon image URL]".

### Problem: The Hebrew caption feels like a literal translation of an English punchline

Cause: The caption was constructed in English and then translated word-for-word.
Solution: Draft Hebrew captions in Hebrew from the start. Use natural Israeli speech patterns. Short, punchy Hebrew uses verb-first constructions ("הבטחנו" not "אנחנו הבטחנו") and colloquial shortening. Avoid calques from English.

### Problem: The satirical angle feels obvious or flat

Cause: The metaphor maps too directly to the topic (e.g., "politician lies" becomes "Pinocchio nose"). This has been done thousands of times.
Solution: Ask what the least obvious angle on this story is. Invert the usual frame: instead of mocking the politician, show the audience cheering despite the obvious absurdity. Reversals, bystander POV, and unexpected scale shifts produce fresher cartoons.

### Problem: The cartoon concept could be misread as endorsing the target's position

Cause: Satire without a clear ironic signal is invisible to some audiences ("Poe's Law").
Solution: Add at least one element that signals irony beyond doubt: an absurd prop, an obviously contradictory caption, or an exaggerated physical reaction from a bystander character. If in doubt, add a small "קריקטורה" label in the corner of the image.
