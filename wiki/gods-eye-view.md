# gods-eye-view

"A spy satellite simulator in your browser, except the data is real" — photorealistic 3D globe (Cesium/Google 3D Tiles) with live flight tracking, AIS vessels, public CCTV feeds, weather, and voice control. Most layers work keyless with fallbacks; live data layers need free API keys (see `.env.example`).

- **Source:** [bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view) (vendored, independent author, 25.6k★)
- **Run:** `npm install && npm run dev`
