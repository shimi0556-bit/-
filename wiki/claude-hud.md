# claude-hud

Claude Code plugin — real-time statusline HUD showing context usage, active tools, running agents, and todo progress, zero config.

- **Source:** [jarrodwatts/claude-hud](https://github.com/jarrodwatts/claude-hud) (vendored, independent author, 27.9k★)
- **Run:** `npm install` inside the folder, then follow the plugin's `README.md` (or install as a Claude Code plugin via its marketplace manifest)
