# 3d-model-extractor

Chrome extension — detects and downloads 3D model files (GLB, GLTF, FBX, OBJ, STL, USDZ, …) from any site via network interception, with an in-browser GLB→STL/3MF converter.

- **Source:** [hoodini/3d-extracter](https://github.com/hoodini/3d-extracter) (vendored, not submoduled)
- **Run:** `chrome://extensions` → Developer mode → Load unpacked → select this folder
