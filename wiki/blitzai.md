# blitzai

Hebrew-first transcription studio — FastAPI backend + Next.js frontend, 4 transcription engines (local faster-whisper, Groq, Gemini, HuggingFace ivrit-ai), YouTube/URL ingestion via yt-dlp, correction studio.

- **Source:** [hoodini/blitzai](https://github.com/hoodini/blitzai) (vendored)
- **Run:** `./start.sh` (see `SETUP_GUIDE.md`)
