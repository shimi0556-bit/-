# decks

Single-file HTML slide decks (Hebrew RTL, 1920×1080 stage scaled to the window). Every deck follows the `deck-edit-mode` skill's shape — `#deck` stage, `.slide` / `.active` sections, `show(n)` navigation — so the in-browser Edit Mode works on all of them.

- **`demo-presentation.html`** — 5-slide demo of the `deck-edit-mode` skill itself.
- **`how-ai-thinks.html`** — "איך בינה מלאכותית חושבת": 12 slides for a general audience, ~15 min. Flow: what "thinking" means → data → tokens → embeddings → neural-net layers → attention → next-token prediction → training (loss/gradient) → reasoning models → limits (hallucination, bias, knowledge cutoff) → working with AI.
- **Run:** open the file directly. Arrow keys / PageUp-PageDown / dots / side buttons navigate (RTL: ← is next). The ✏️ button in the corner opens Edit Mode; Cmd+S downloads `<name>-edited.html`.

## Notes

### how-ai-thinks.html
- **Canva was the first choice (user preference: Canva + GitHub + Photoshop) but both `create-design` and `generate-image` failed with `quota_exceeded`** — the account's credits were spent. The deck was built as HTML instead. If credits come back, the same 12-slide outline can be re-run through Canva `create-design` and exported to PPTX/PDF.
- **Photoshop step:** the cover art (an SVG neural net) was rendered to a 1600×1600 PNG, uploaded to Adobe via `asset_initialize_file_upload` → PUT to the transfer URL → `asset_finalize_file_upload` (works through the agent proxy), then run through `image_apply_adjustments` (vibrance +35, contrast +12) and `image_add_grain` (18). The result is embedded in slide 1 as a WebP data URI (~480 KB; the file is ~740 KB total) and faded at the edges with a CSS `mask-image` so it blends into the slide background. Adobe has no generative image tools in this environment, so only adjustments/grain were possible.
- **Diagrams are inline SVG**, generated by a throwaway Python script (not committed — the HTML is the source of truth now; edit the HTML or use Edit Mode). All numbers on the slides (token IDs, attention percentages, next-token probabilities, weights `0.82` / `−0.31`) are **illustrative** and labelled as such on the slides.
- **Gotchas hit while building (worth remembering for any SVG in RTL decks):**
  - An SVG `<line>` that is perfectly horizontal has a zero-height bounding box, so an `objectBoundingBox` gradient stroke **and** a default-region `<filter>` both make it disappear. Use `gradientUnits="userSpaceOnUse"` and `filterUnits="userSpaceOnUse"` with an explicit region.
  - Inside an RTL page, SVG `<text>` inherits `direction: rtl`: `text-anchor="start"` then extends *leftwards*, and a leading minus sign (`−0.31`) renders on the wrong side. Set `direction="ltr"` on those `<text>` elements.
  - Don't stack `padding-bottom` hacks on a flex child that has a sibling below it (slide 12's cards collapsed) — use `margin-bottom` on the child instead.
- **Verified** with Playwright (Chromium): all 12 slides screenshotted at 1920×1080, no JS errors, no content overflow (only the intentional background glows exceed the stage), Edit Mode opens and selects elements, navigation works after the editor was injected.
