One-time setup: add your own Google OAuth client ID

To keep this extension free of any shared backend, it talks to the Drive API using your own Google Cloud OAuth client. This is a one-time setup:

  1. Go to the Google Cloud Console credentials page (create a project first if you don't have one).
  2. Enable the Google Drive API under "APIs & Services".
  3. Create an OAuth client ID of type Chrome Extension, using this extension's ID: loading…
  4. Copy the generated client ID into manifest.json's oauth2.client_id field, then reload the extension from chrome://extensions.

Only the drive.readonly scope is requested — this extension can list and open your files, but cannot edit, delete, or share anything.
