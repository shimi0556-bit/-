# 🎸 גיטרה FX — מיקסר אפקטים לגיטרה חשמלית

זו תוכנה שרצה בדפדפן. מחברים את הגיטרה למחשב, והמחשב מעבד את הצליל בזמן אמת: מגבר, קבינט ו-20 אפקטים. הצליל יוצא למגבר או לאוזניות.

**קובץ אחד** (`index.html`). בלי התקנה, בלי אינטרנט ובלי שרת. לוחצים עליו פעמיים והוא נפתח ב-Chrome או Edge. עובד גם מדיסק און קי.

## איך מחברים

```
🎸 גיטרה  →  🎛 כרטיס קול USB (כניסת Hi-Z / Instrument)  →  💻 מחשב  →  🔊 מגבר / אוזניות
```

- **כרטיס קול:** Behringer UM2, Focusrite Scarlett Solo, או כבל Behringer Guitar Link (UCG102). כניסת המיקרופון של המחשב לא מתאימה לגיטרה חשמלית.
- **כניסה במגבר:**
  - הכי טוב: **Return / FX Loop / AUX**, רמקול מוגבר או אוזניות. בתוכנה בוחרים "סימולציה מלאה".
  - אם יש רק **כניסת גיטרה רגילה**: בוחרים "כניסת הגיטרה הרגילה של המגבר". התוכנה מכבה את סימולציית המגבר והקבינט ומתנהגת כמו לוח פדלים.
- לחיבור למגבר עם כניסה אחת בוחרים **מונו**.
- תמיד מתחילים עם ווליום נמוך.

## מה יש בפנים

| קבוצה | אפקטים |
|---|---|
| דינמיקה | נויז גייט, קומפרסור |
| פילטרים | וואה (אוטומטי לפי המגע / ידני / מתנדנד) |
| גובה צליל | אוקטבר (אוקטבה למטה ולמעלה), הרמונייזר עם 2 קולות |
| דיסטורשן | בוסטר, אוברדרייב (בסגנון TS), דיסטורשן (בסגנון RAT), פאז (בסגנון Muff), לו-פיי/ביטקראשר |
| מגבר | 6 דגמים: ג׳אז נקי, נקי אמריקאי, בריטי מצלצל, בריטי קראנץ׳, ליד חם, מטאל מודרני. כולם עם גיין, באס, מיד, טרבל, פרזנס, עומק, מאסטר וברייט |
| קבינט | 5 רמקולים, 3 מיקומי מיקרופון, **טעינת IR אמיתי מקובץ WAV** |
| אקולייזר | 7 פסים |
| מודולציה | קורוס/ויברטו, פלנג׳ר, פייזר (4–12 שלבים), טרמולו/פאן סטריאו, רינג מודולטור |
| זמן | דיליי (דיגיטלי / אנלוגי / טייפ / פינג-פונג) עם טאפ טמפו, ריוורב (חדר / פלייט / אולם / קפיץ / אולם ענק / אמביינט). הזנב ממשיך להישמע גם אחרי שמכבים את הפדל |

ועוד:

- **17 פריסטים מוכנים**: נקי, בלוז, רוק, סולו, מטאל, פאנק, אמביינט, גראנג׳, סרף ועוד. אפשר לשמור פריסטים משלך ולייצא/לייבא אותם.
- **כיוונון (טיונר)** מדויק, עם השתקה בזמן הכיוון.
- **לופר** של עד 60 שניות, עם שכבות וביטול שכבה.
- **הקלטה לקובץ WAV** באיכות 24 ביט.
- **ריף הדגמה**, כדי לשמוע את האפקטים גם בלי גיטרה. אפשר גם לטעון הקלטת DI מקובץ.
- **בקר רגליים MIDI**: Program Change מחליף פריסט, ויש "למידת MIDI" לכל כפתור ופדל.
- גרירה לשינוי סדר הפדלים, זיהוי אוטומטי של ערוץ הגיטרה בכרטיס הקול, ולימיטר ביציאה שמגן על הרמקולים.

## קיצורי מקלדת

`1`–`9`, `0` הדלקת פדלים · `[` `]` פריסט קודם/הבא · `B` עקיפה · `M` השתקה · `T` כיוון · `L` לופר · `Space` טאפ טמפו

## השהייה (Latency)

בדפדפן ההשהייה היא בדרך כלל 10–25 מילישניות, וזה מספיק לנגינה. כדי להוריד אותה:

- משתמשים ב-Chrome או Edge, ובוחרים "השהייה: נמוכה ביותר".
- ב-Windows מכבים "שיפורי שמע", ומגדירים 48kHz גם לכניסה וגם ליציאה.
- מחברים את המחשב הנייד לחשמל.

אם שומעים קליקים, בוחרים "יציבה".

## איכות הצליל (למי שמתעניין)

- כל העיבוד של הדיסטורשן והמגבר רץ ב-AudioWorklet, עם **ADAA** (anti-derivative anti-aliasing). כך הדיסטורשן נקי מ-aliasing **בלי תוספת השהייה**. ה-oversampling המובנה של הדפדפן מוסיף כ-4 מילישניות לכל שלב, ולכן לא השתמשנו בו.
- הקבינט והריוורב עובדים בקונבולוציה (IR), והרמות שלהם מנורמלות.
- רמות הפלט כוילו בבדיקות: כל דגמי המגבר וכל הפריסטים יוצאים בעוצמה דומה, וגם ה"גיין" של פדלי הדיסטורשן לא מקפיץ את הווליום.
