# נץ הברזל (Iron Hawk 3D)

משחק מטוס קרב בתלת־ממד בדפדפן: טסים מעל עולם פתוח ומשמידים מפלצות ענק בשלושה אזורים.
קובץ אחד (`index.html`) שעובד בלי אינטרנט ובלי שרת: הקוד, הגופנים והצלילים ארוזים בתוכו.

## האזורים

| אזור | משימה |
|---|---|
| **העמק הירוק** | להשמיד 14 מפלצות: רצים, שריונים וענקים. |
| **הקניון האדום** | להשמיד 18 מפלצות: טורפים יורקי אש וכנפיים שרודפות אחרי המטוס, בין קירות הקניון. |
| **הר הגעש** | קרב בוס מול **מלך הלבה**: להשמיד את שלושת גבישי האש על גבו, ואז את הלב שנחשף. |

כל האזורים פתוחים מההתחלה. יש שלושה מטוסים לכל משימה. ניצחון נותן כוכב אחד, ניצחון שבו המטוס הופל פעם אחת לכל היותר נותן שניים, ושלושה כוכבים מקבלים על ניצחון בלי אף הפלה בתוך זמן היעד (6, 8 ו־9 דקות).

## המפלצות

רץ, שריון, ענק, טורף (יורק כדורי אש), כנף (מעופפת) ומלך הלבה. כל מפלצת שפגשתם נפתחת ב"אטלס המפלצות" שבתפריט.

## שליטה

**מקלדת ועכבר**

| מקש | פעולה |
|---|---|
| `↑` `↓` או `W` `S` | אף למעלה / למטה |
| `←` `→` או `A` `D` | הטיה ופנייה |
| `Q` `E` | הגה כיוון |
| רווח או לחיצה שמאלית | תותח |
| `F` או לחיצה ימנית | טיל (ננעל לבד על מטרה מלפנים) |
| `Shift` | טורבו |
| `Ctrl` או `X` | האטה |
| `C` | החלפת מצלמה |
| `Esc` או `P` | השהיה |
| `M` | השתקה |

**מסך מגע:** אגודל שמאל בכל מקום בחצי השמאלי של המסך הוא ג'ויסטיק. מימין יש כפתורי ירי, טיל, טורבו והאטה.

**שלט משחק:** סטיק שמאלי לטיסה, RT לתותח, A או RB לטיל, LB לטורבו, LT להאטה, Y למצלמה.

## הרצה

פותחים את `index.html` ישירות בדפדפן, או דרך המגרש שבשורש הריפו (`../index.html#ironhawk`).
בהגדרות אפשר להוריד איכות גרפיקה אם המחשב או הטלפון איטיים.

## בנייה מהמקור

```bash
npm install
npm run build   # בונה את index.html המוקטן (בערך 1.3MB)
npm run dev     # אותו קובץ בלי הקטנה, נוח לדיבוג
```

הקוד ב־`src/`: `world/` (שמיים, קרקע, מים ולבה, צמחייה, עננים, אזורים), `actors/` (מטוס, מפלצות, נשק, תיבות),
`core/` (רינדור, מצלמה, קלט, קול), `fx/` (פיצוצים ועשן), `ui/` (תפריטים ומסכי מצב). `tools/build.mjs` אורז הכול לקובץ אחד.
Three.js r186, בלי ספריות נוספות בזמן ריצה.

## נכסים

- **צלילים:** 19 אפקטים קוליים שנוצרו עם ElevenLabs (פיצוצים, שאגות, טיל, רוח ועוד), בלי קולות דיבור ובלי שירים.
  עובדו עם `tools/process_sfx.py` ונשמרים ב־`assets/sfx/`.
- **מרקמים:** נוצרים בקוד בזמן טעינה (`src/core/textures.js`).
- **תמונות:** `tools/gen_images.py` מיועד ליצירת תמונות עם Gemini. מפתח ה־API נקרא רק ממשתנה הסביבה
  `GEMINI_API_KEY` ואף פעם לא נשמר בריפו. תמונות מוכנות שמים ב־`assets/img/`, והבנייה אורזת אותן אוטומטית.
