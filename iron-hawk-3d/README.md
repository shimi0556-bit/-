# נץ הברזל (Iron Hawk 3D)

משחק יריות בתלת־ממד בדפדפן, מגוף ראשון: אתם צמודים לחלון הקדמי, ושני תותחים מציצים מהפינות.
המסלול לוקח אתכם דרך האזור, פעם בריצה על הקרקע ופעם בטיסה נמוכה, ובכל עצירה קופץ מארב:
גלים של מפלצות פורצים מהאדמה וצוללים מהשמיים, ורצים ישר אל החלון.
קובץ אחד (`index.html`) שעובד בלי אינטרנט ובלי שרת: הקוד, הגופנים והצלילים ארוזים בתוכו.

## האזורים

| אזור | הדרך |
|---|---|
| **העמק הירוק** | ארבעה מארבים: ריצה, טיסה, ריצה וטיסה. רצים, שריונים וענקים. |
| **הקניון האדום** | ארבעה מארבים בתחתית הקניון ובין הקירות. טורפים יורקי אש, כנפיים שצוללות על החלון ושריונים. |
| **הר הגעש** | שלושה מארבים בין נהרות הלבה, ובסוף **מלך הלבה**: להשמיד את שלושת גבישי האש על גבו, ואז את הלב שנחשף. |

בכל משימה יש מגן ושלושה חיים. כשהמגן מתרוקן הולכים חיים אחד, והמגן משחרר הדף שזורק אחורה את כל מה שקרוב לחלון.
ניצחון נותן כוכב אחד, ניצחון שבו אבדו חיים אחד לכל היותר נותן שניים, ושלושה כוכבים מקבלים על ניצחון בלי לאבד חיים ועם פחות מ־150 נזק.
מפלצות גדולות מפילות לפעמים תיבות: ירייה בתיבה פותחת אותה (תיקון למגן, מדף טילים מלא, או קירור לתותחים).

## המפלצות

רץ, שריון, ענק, טורף (יורק כדורי אש), כנף (מעופפת) ומלך הלבה. כל מפלצת שפגשתם נפתחת ב"אטלס המפלצות" שבתפריט.

## משקפי תלת־ממד

בהגדרות יש מתג **משקפי תלת־ממד** (אדום־תכלת). כשהוא דולק, מפלצות שמתקרבות לחלון יוצאות מהמסך.

## שליטה

**עכבר ומקלדת**

| מקש | פעולה |
|---|---|
| הזזת העכבר | כוונת |
| לחיצה שמאלית, רווח או `J` | תותחים (לחיצה ממושכת) |
| לחיצה ימנית, `F`, `K` או `Enter` | טיל (ננעל לבד על המטרה שליד הכוונת) |
| חיצים או `W` `A` `S` `D` | הזזת הכוונת בלי עכבר |
| `Esc` או `P` | השהיה |
| `M` | השתקה |

התותחים מתחממים: ירי בצרורות קצרים שומר אותם קרים. טילים נטענים מחדש לאט.

**מסך מגע:** אצבע בכל מקום על המסך מכוונת ויורה (הכוונת מופיעה קצת מעל האצבע). כפתור הטיל בפינה.

**שלט משחק:** כל אחד מהסטיקים מזיז את הכוונת, RT או LT לתותחים, A, RB או LB לטיל, Start להשהיה.

## הרצה

פותחים את `index.html` ישירות בדפדפן, או דרך המגרש שבשורש הריפו (`../index.html#ironhawk`).
בהגדרות אפשר להוריד איכות גרפיקה אם המחשב או הטלפון איטיים.

## בנייה מהמקור

```bash
npm install
npm run build   # בונה את index.html המוקטן (בערך 1.3MB)
npm run dev     # אותו קובץ בלי הקטנה, נוח לדיבוג
```

הקוד ב־`src/`: `world/` (שמיים, קרקע, מים ולבה, צמחייה, עננים, המסלול, אזורים), `actors/` (התותחים, מפלצות, נשק, תיבות),
`core/` (רינדור, מצלמה, קלט, קול), `fx/` (פיצוצים ועשן), `ui/` (תפריטים ומסכי מצב). `tools/build.mjs` אורז הכול לקובץ אחד.
Three.js r186, בלי ספריות נוספות בזמן ריצה.

## נכסים

- **צלילים:** 19 אפקטים קוליים שנוצרו עם ElevenLabs (פיצוצים, שאגות, טיל, רוח ועוד), בלי קולות דיבור ובלי שירים.
  עובדו עם `tools/process_sfx.py` ונשמרים ב־`assets/sfx/`.
- **מרקמים:** נוצרים בקוד בזמן טעינה (`src/core/textures.js`).
- **תמונות:** `tools/gen_images.py` מיועד ליצירת תמונות עם Gemini. מפתח ה־API נקרא רק ממשתנה הסביבה
  `GEMINI_API_KEY` ואף פעם לא נשמר בריפו. תמונות מוכנות שמים ב־`assets/img/`, והבנייה אורזת אותן אוטומטית.
