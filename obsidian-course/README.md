# קורס Obsidian אינטראקטיבי

קורס HTML עצמאי (בלי build, בלי תלות ברשת) על [Obsidian](https://obsidian.md) — אפליקציית הערות מקושרות מבוססת Markdown. נבנה בעברית, RTL, עם מעקב התקדמות שנשמר בדפדפן (localStorage), שאלוני תרגול בכל שיעור, מבחן מסכם, ותעודת סיום להדפסה.

## איך מריצים

פותחים את `index.html` ישירות בדפדפן — אין שרת, אין התקנה.

## מבנה הקורס

- **שלב 1 · מתחילים** (7 שיעורים) — Vault, Markdown בסיסי, Wikilinks, Backlinks, תגיות.
- **שלב 2 · בינוני** (7 שיעורים) — Graph View, ניווט מהיר, חיפוש מתקדם, Templates, Frontmatter, Canvas, Core Plugins.
- **שלב 3 · מקצוענים** (7 שיעורים) — Community Plugins, Dataview, סנכרון, התרחיש של פתיחת `wiki/` מהריפו הזה כ-vault, אבטחה, השוואה לכלים דומים, ניהול vault גדול.
- דף קיצורי מקלדת (להדפסה), מבחן מסכם (סף מעבר 80%), תעודת סיום.

נבנה עם סקיל `interactive-course-builder` (`.claude/skills`), על בסיס `template.html` הקבוע של הסקיל.
