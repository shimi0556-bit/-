# Verifiability

**Claim:** classical software automates what you can specify; learned software automates what you can verify. Tasks with a cheap, automatic success signal improve fastest, which is why AI progress is jagged.

> Software 1.0 easily automates what you can specify.
> — `raw/bearblog/verifiability.md`

> Software 2.0 easily automates what you can verify.
> — `raw/bearblog/verifiability.md`

> It modifies the code, trains for 5 minutes, checks if the result improved, keeps or discards, and repeats.
> — `raw/github/autoresearch--README.md`

Why it matters for this agent: teaching by building turns understanding into a verifiable task. Running the code gives the learner (and the agent) a reward signal, which is the idea behind [rule 5](../rules.md) and the run-gate hook.
