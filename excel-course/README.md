# קורס Excel מלא — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת. אותה תבנית קורס כמו [`../powerpoint-course/`](../powerpoint-course).

## מה יש בפנים

- **3 שלבים · 21 שיעורים**: מתחילים (ממשק, חוברות/גיליונות, נתונים, נוסחאות והפניות, עיצוב, מיון/סינון/הדפסה) → בינוני (פונקציות, VLOOKUP/INDEX-MATCH/XLOOKUP, טבלאות ועיצוב מותנה, PivotTables, גרפים, Data Validation, עבודה עם כמה גיליונות) → מקצוענים (קיצורי מקלדת, נוסחאות מערך דינמיות, Power Query, Power Pivot ו-DAX, מאקרו/VBA, דשבורדים אינטראקטיביים, שיתוף פעולה ואבטחה, עקרונות למודלים מקצועיים).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר.
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open excel-course/index.html   # macOS
xdg-open excel-course/index.html   # Linux
```
