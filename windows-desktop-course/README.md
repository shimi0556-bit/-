# קורס שולחן העבודה בווינדוס — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת. אותה תבנית קורס כמו [`../powerpoint-course/`](../powerpoint-course), [`../excel-course/`](../excel-course) ו-[`../gmail-course/`](../gmail-course), בנוי דרך הסקיל [`interactive-course-builder`](../claude-skills/interactive-course-builder).

## מה יש בפנים

- **3 שלבים · 21 שיעורים**: מתחילים (שולחן העבודה, שורת המשימות, תפריט Start, ניהול חלונות בסיסי, קבצים ותיקיות, חיפוש, קיצורי דרך) → בינוני (Snap Layouts ושולחנות וירטואליים, התאמה אישית, ארגון אייקונים, Widgets/Action Center, File Explorer מתקדם, קיצורי מקלדת, הגדרות מערכת) → מקצוענים (חשבונות והרשאות, אבטחה, Task Manager, גיבוי ושחזור, נגישות, PowerShell/CMD, טיפים לניהול מקצועי + השוואת Windows 10/11).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר.
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.
- לחיצה אחת על "אחורה" בדפדפן יוצאת מהקורס לגמרי (לא מדפדפת בין שיעורים פנימיים).

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open windows-desktop-course/index.html   # macOS
xdg-open windows-desktop-course/index.html   # Linux
```
