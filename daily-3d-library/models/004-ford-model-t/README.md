# #004 Ford Model T Touring (1915, brass era)

דגם פרוצדורלי ב־Three.js (אפס קבצי מודל/תמונות): 164 חלקים בעלי שם ותיאור בעברית, ~112K משולשים, 509 רשתות.

## מה בנוי, לפי מערכת
- **מרכב:** דפנות גוף על שלד עץ (כולל חריץ לדלתות אחוריות), כנפיים קדמיות ואחוריות (סוויפ לאורך קשת סביב הציר, עם נירות), לוחות דריכה מחורצים, מכסה מנוע דו־חלקי עם תריסים (נפתח בציר באמצע), קאול, קיר אש, ארגזי מושב, שתי לוחיות רישוי.
- **דלתות:** שתי דלתות אחוריות על צירים אחוריים עם ידיות; הדלתות הקדמיות מוצגות כקו מוטבע (נפתחות בלי צורך, ראו "הפשטות").
- **גג ושמשה:** ארבע קשתות מתקפלות כמניפה, בד גג, חלון אחורי, וילונות צד, שמשה דו־חלקית (העליונה מתקפלת קדימה), מגב ידני.
- **תאורה:** פנסי פליז חשמליים (מגנטו), מנורות נפט צד, פנס זנב אדום, צופר בולב.
- **רדיאטור:** מעטפת פליז, ראש עם כיתוב Ford, ליבת חלת דבש, פקק, ברז ניקוז, צינורות, מאוורר.
- **מנוע/הצתה/דלק/תמסורת:** בלוק וראש (15 ברגים), אגן, בוכנות ומוטות מונפשים, גל ארכובה, גלגל תנופה עם 16 מגנטים וסלילי מגנטו, קופסת סלילים, מצתים, קרבורטור, יניקה ופליטה בצד שמאל, ממפלר, מיכל גרביטציה, תיבה פלנטרית עם גלגלי שיניים וסרטי בלימה, צינור מומנט, דיפרנציאל.
- **שלדה וגלגלים:** אורכי C עם ניטים, קורות, ציר קדמי מסוג I, קפיצי עלים רוחביים, מוטות רדיוס, היגוי, בלמי תוף; ארבעה גלגלי עץ (12 חישורים, פלגה, נאב, פקק פליז, חישוק קלינצ׳ר, צמיג 30×3 / 30×3½) וגלגל חילוף.
- **כפתורים/מתגים:** hood, doors, top, curtains, windshield, engine, drive, lights.

## מספרים
בסיס גלגלים 2.54 מ׳, מסלול 1.42 מ׳, צמיג 30 אינץ׳ (R=0.381), אורך ≈3.4–3.5 מ׳.

## הפשטות / פערים ידועים
- דלתות קדמיות דמה; מיקום הקרבורטור והמניפולדים בצד שמאל הוא שחזור מושכל.
- חלק מהחלקים הפנימיים (תמסורת, גלגלי שיניים) מייצגים ולא מדויקים בשיניים.
- גוף הרכב מורכב מקטעים שטוחים ולא מוסדר בעקומות כמו בתמונה האמיתית.
