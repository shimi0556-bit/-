# שימוטרון · Shimotron

מנוע תלת־ממד לדפדפן, עם עורך מלא בעברית ומשחק מירוצים שבנוי עליו. כל העולם נבנה בזמן אמת בקוד: איים עם הרים, חופים, ים, יער, מסלולים ומכוניות. אין בו אף קובץ תמונה, מודל או סאונד.

A browser 3D engine (Three.js r186 + cannon-es) with a full Hebrew editor, plus **Shimotron Rally**, a racing game built on it. Everything is procedural: no image, model or audio files.

![](https://img.shields.io/badge/WebGL-2-39d9ff) ![](https://img.shields.io/badge/three.js-r186-ffb020) ![](https://img.shields.io/badge/physics-cannon--es-3ddc97)

## הרצה

| דרך | פקודה |
|---|---|
| **הכי פשוט:** לפתוח את הקבצים המוכנים | `dist/index.html` (המנוע והעורך), `dist/race.html` (משחק המירוצים). כל אחד הוא קובץ אחד שמכיל הכול ונפתח ישירות מהדיסק |
| פיתוח עם טעינה חיה | `npm install && npm run dev`, ואז `/` לעורך או `/race.html` למשחק |
| בנייה מחדש | `npm run build` (שניהם), או `npm run build:engine` / `npm run build:race` |

אפשר לכפות רמת איכות דרך הכתובת: `#low`, `#medium`, `#high` או `#ultra` (למשל `race.html#ultra`). בלי זה, המנוע בוחר רמה לפי כרטיס המסך.

## שימוטרון ראלי · משחק המירוצים

חמישה איים, ולכל אחד מסלול משלו באורך של יותר משלושה קילומטרים, שש מכוניות ואליפות.

| # | אי | מה מיוחד בו |
|---|---|---|
| 1 | **אי האורנים** | יערות מחטניים, רכס הרים בצפון וחוף ארוך. אחר צהריים |
| 2 | **אי הדיונות** | חולות כתומים, קקטוסים, דקלים ועצים מתים. אבק מדבר באוויר ושעת זהב |
| 3 | **אי הלגונה** | לגונה טורקיז בלב האי, חוף לבן ודקלים. צהריים |
| 4 | **אי הקרח** | פסגות מושלגות, אורנים קפואים ושלג שיורד. בוקר מעונן |
| 5 | **אי הלבה** | הר געש עם אגם לבה זוהר וענן אפר, סלע שחור. מירוץ לילה לאור הפנסים |

**איך זה בנוי**
- **האי:** מתכון פרמטרי (רדיוס, רכסים, דיונות, הר געש, לגונה) ופלטת צבעים לכל ביומה, כולל קו שלג.
- **המסלול:** מחולל עם זרע קבוע מנסה עשרות לולאות סביב מרכז האי ובוחר את הטובה ביותר: בלי פניות צרות מדי, בלי מים, בלי קטעים שנוגעים זה בזה, ועם מספיק פניות. אחר כך הכביש נחצב בשטח: פרופיל גובה עם שיפוע של עד 8.5%, פסגות מעוגלות, הטיה בפניות, שוליים מחצץ, שפות אדומות־לבנות, מעקות, שער זינוק עם רמזורים, יציע עם קהל, שלטי בלימה, ערימות צמיגים ופנסי תאורה.
- **המכונית:** דגם GT פרוצדורלי (מעטפת שנבנית מחתכים, זכוכית, פנסים, כנף ומספרים) על `RaycastVehicle`. הנעה לכל הגלגלים, תיבת הילוכים אוטומטית, היגוי שמתכווץ עם המהירות, בלם יד לדריפטים, ניטרו, כוח הצמדה, גרר, יניקה מאחורי מכונית אחרת (slipstream), אחיזה לפי משטח (אספלט, שפה, חצץ, דשא, חול, שלג) וסיוע יציבות.
- **היריבים:** נוהגים על קו מירוץ שמחושב מראש (עקמומיות מינימלית) עם פרופיל מהירויות שמתחשב באחיזה, בבלימה ובפסגות. הם עוקפים בצד שיש בו מקום, שומרים מרחק כשהם צמודים, עושים לפעמים טעויות קטנות, ויודעים לחזור למסלול. שלוש רמות קושי, ו־rubber banding עדין.
- **המירוץ:** רמזורי זינוק, זמני הקפה, פערים לפי נקודות ביקורת, דירוג חי, אזהרת כיוון שגוי, חזרה למסלול (`R`), מסך תוצאות, שיאי הקפה לכל אי, ואליפות של חמישה שלבים עם ניקוד.
- **תחושה:** סימני צמיגים, עשן, אבק בצבע הקרקע, ניצוצות ממעקות, להבות ניטרו, רעידות מצלמה, ומנוע, צמיגים ורוח מסונתזים.

**שליטה**

| מקלדת | ג׳ויסטיק | פעולה |
|---|---|---|
| `W` / `↑` | RT או A | גז |
| `S` / `↓` | LT או B | בלם, ורוורס כשעומדים |
| `A` `D` / `←` `→` | סטיק שמאלי | היגוי |
| `רווח` | X או RB | בלם יד |
| `Shift` / `N` | Y או LB | ניטרו |
| `C` · `B` | | החלפת מצלמה (מרדף, רחוק, מכסה מנוע, פגוש) · מבט לאחור |
| `R` · `Esc` · `M` | | חזרה למסלול · עצירה · השתקה |

במסך מגע מופיעים כפתורים: היגוי משמאל, גז, בלם, ניטרו ובלם יד מימין.

**כלים**
- `node tools/racesim.mjs <island> <seconds> <cars>`: מריץ מירוץ שלם בלי גרפיקה (שטח, מסלול, פיזיקה ובינה מלאכותית) ומדפיס זמני הקפה, התהפכויות וחזרות למסלול. כך כיוונו את הנהגים.
- `node tools/cartest.mjs`: כיול הרכב על משטח שטוח: 0–100, מהירות מרבית, מרחק בלימה ואחיזה בפנייה.
- `node tools/stages.mjs <out-dir>`: מצייר מפה של כל אי עם המסלול שלו.

## מה יש בפנים

**תאורה ורינדור**
- חומרי PBR (מתכת, זכוכית שוברת אור, ציפוי שקוף, קטיפה, קשתיות) עם תאורה מבוססת תמונה (IBL) שמחושבת מחדש מהשמיים החיים.
- שמיים אטמוספריים (Preetham) עם עננים, ירח, כוכבים שמוסתרים מאחורי העננים, ומחזור יום/לילה מלא.
- אור השמש, צבע האופק, הערפל והחשיפה נגזרים כולם מאותו מודל שמיים (העתק שלו רץ ב־CPU), ולכן תמיד מתאימים זה לזה.
- חשיפה אוטומטית (התאמת עין), ערפל גובה עם פיזור אור שמש, וצללים רכים שעוקבים אחרי המצלמה בלי ריצוד.
- שרשרת אפקטים: MSAA → GTAO → קרני אור (god rays) → עומק שדה → Bloom → מיפוי טונים AgX/ACES/Neutral → דירוג צבע, וינייטה, גרעיניות, ראיית לילה, קו מתאר לבחירה → FXAA.

**עולם**
- שטח פרוצדורלי בחלוקה לאריחים, עם 4 שכבות טקסטורה (דשא, חול, עפר, סלע), מיזוג לפי גובה, טקסטורת סלע משולשת (triplanar), חול רטוב בקו המים וקאוסטיקה מתחת למים.
- ים עם גלי גרסטנר, צבע לפי עומק, קצף חוף, פיזור אור בפסגות הגלים וציפה פיזיקלית.
- אורנים ואלונים מכרטיסי עלווה עם שקיפות, תאורה מבעד לעלים ותנועה ברוח. דשא ופרחים מונפשים, וסלעים. הכול מחולק לתאים כדי שהמצלמה והצללים יסננו מה שלא נראה.
- כל הטקסטורות נאפות ב־GPU בזמן הטעינה, כולל מפות נורמל ו־ORM.

**מערכות**
- פיזיקה: cannon-es בקצב קבוע של 60Hz עם אינטרפולציה, חומרי מגע, צלילי פגיעה וניצוצות, פיצוצים וציפה.
- חלקיקים: אש, עשן, ניצוצות, זוהר ואבק, כולם במאגר (pool) ובקריאת ציור אחת לכל מערכת.
- סאונד מסונתז לגמרי: רוח, גלים, ציפורים ביום, צרצרים בלילה, מדורה במרחב תלת־ממדי, פגיעות לפי חומר וצעדים לפי משטח.
- מצלמה: עורך (orbit), טיסה חופשית, הליכה בגוף ראשון עם פיזיקה וקפיצה, וסיור קולנועי.
- איכות: 4 רמות, רזולוציה דינמית ששומרת על 60fps, וזכוכית ששוברת אור רק כשהיא קרובה מספיק.

**עורך**
- היררכיה עם חיפוש, פלטת 12 אובייקטים מוכנים, ובורר מאפיינים: מיקום, סיבוב, קנה מידה, חומר, אור ופיזיקה.
- ידיות הזזה, סיבוב וקנה מידה, וקו מתאר ענברי סביב האובייקט הנבחר.
- לשוניות לסביבה (שעה, עננים, ערפל, רוח, גלים, כבידה, מהירות זמן) ולגרפיקה.
- שמירה בדפדפן, ייצוא וייבוא JSON, צילום מסך, מצב צילום עם עומק שדה, ומסוף להרצת סקריפטים.
- תמיכה בנייד: פאנלים תחתונים וג׳ויסטיקים למגע.

## שימוש בקוד (API)

כל המנוע זמין בקונסול דרך `window.shimotron`:

```js
const { engine } = shimotron;

// להוסיף אובייקט מוכן
const ball = engine.spawn('ball', { position: [0, 12, 0], radius: 0.4, color: '#39d9ff' });

// להעיף אותו
ball.body.velocity.set(0, 8, -6);

// לשנות שעה, עננים ורוח
engine.atmosphere.setTime(18.2);
engine.atmosphere.cloudCoverage = 0.6;
engine.atmosphere.wind.strength = 2;

// להוסיף רכיב התנהגות משלכם (על גוף סטטי, כדי שהפיזיקה לא תדרוס את הסיבוב)
const knot = engine.spawn('knot', { position: [0, 9, 0], dynamic: false });
class Spinner extends shimotron.Component {
  update(dt) { this.entity.object3D.rotation.y += dt; }
}
knot.addComponent(new Spinner());

// להירשם לאירועים
engine.events.on('impact', ({ point, speed }) => console.log('בום', speed.toFixed(1)));
```

אובייקטים מוכנים: `cube`, `ball`, `cylinder`, `knot`, `crate`, `barrel`, `domino`, `pillar`, `lamp`, `orb`, `fire`, `rock`.
להוספת סוג חדש משתמשים ב־`engine.registerPrefab(kind, { defaults, create(engine, params) })`.

## ביצועים

**במשחק:** הפיזיקה רצה ב־120Hz עם צובר זמן שלא מאבד זמן גם כשפריים מתעכב. גלגלים על הכביש לא בודקים משולשים: הם מחשבים חיתוך מדויק מול משטח הכביש (גובה, הטיה ושוליים). ארגזי השלדה לא נבדקים מול השטח, והמעקות מקובצים לגופים מרובי צורות. מירוץ של 6 מכוניות ו־4 דקות רץ ב־Node בכ־10 שניות.

**בעורך:**

בסצנת ההדגמה, ברמת "גבוהה", פריים טיפוסי הוא בערך 300 עד 450 קריאות ציור וכמיליון משולשים, כולל מעבר הצללים. זה נמדד עם `renderer.info`, ושורת הסטטוס בתחתית המסך מציגה את המספרים בזמן אמת. אם הקצב יורד מתחת ל־60fps, הרזולוציה הדינמית מורידה את הרזולוציה בהדרגה. ברמות נמוכה ובינונית אין GTAO ואין MSAA (במקומו FXAA), והצללים והצמחייה קלים יותר.

## הערות

- נדרש דפדפן עם WebGL 2: Chrome, Edge, Firefox או Safari עדכני.
- מסוף הסקריפטים משתמש ב־`new Function`, ובסביבות עם מדיניות אבטחה קשוחה (למשל תצוגה מוטמעת) הוא עלול להיחסם. בקובץ המקומי הוא עובד.
- הגופנים (Karantina, IBM Plex Sans Hebrew, JetBrains Mono) נטענים מ־Google Fonts. בלי אינטרנט המנוע משתמש בגופני המערכת, וגם הלוגו התלת־ממדי נבנה מגופן מערכת.
