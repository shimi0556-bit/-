# אטלס המוח (brain-graph)

גרף ידע אישי שמסודר **בצורת מוח**: כל סוג של ידע נמצא באזור המוח שמתאים לתפקוד שלו. הרגלים בגרעיני הבסיס, ערכים ומטרות בקליפת המצח, רגשות באמיגדלה, זיכרונות בהיפוקמפוס, מיומנויות במוחון, ידע ושפה באונה הרקתית, דימויים באונה העורפית, וכן הלאה (12 אזורים).

קובץ HTML אחד, בלי התקנה ובלי שרת.

## הרצה

פותחים את `index.html` בדפדפן. הכול נשמר ב־`localStorage` של הדפדפן. בלי מפתח API האפליקציה עובדת במצב מקומי (חילוץ לפי מילים), ועם מפתח ה-AI עושה את העבודה.

אין מפתח? אפשר ללחוץ "הגרף ריק – לחץ לטעינת דוגמה" ולנסות.

## מה יש בה

- **הוספת ידע**: הדבקת טקסט, קבצים (txt, md, html, json, csv, pdf, docx; גרירה ושחרור גם עובדים) וקישורים לאתרים. ה-AI מחלץ רעיונות, בוחר לכל אחד אזור וסוג (ערך, הרגל, רגש, זיכרון, מיומנות…), מקשר אותו לצמתים שכבר קיימים ומאחד כפילויות. כל מסמך הופך לצומת מקור (ריבוע) שמחובר לכל מה שחולץ ממנו.
- **פריסה כמו מוח**: כל צומת נמשך לאזור שלו. אזור שמתמלא "מתנפח". גרירת צומת לאזור אחר משייכת אותו מחדש.
- **פקודה ל-AI** (שורה בתחתית): "מה גורם לי לדחות משימות?", "הוסף הרגל חדש", "ייצא ל-Photoshop". ה-AI מחפש איפה בגרף הבקשה "גרה", ואז האפליקציה **עוברת על הגרף צומת אחרי צומת**: כל צומת שנקרא מתעורר, הקשת שעברו בה נצבעת בזהב, והאזור כולו נצבע בצבע שלו ומתחיל לזהור. אחרי זה ה-AI עונה לפי הזיכרון שנקרא, והצמתים שהשתמש בהם נשארים מסומנים.
- **שינויים בגרף רק באישור**: הצעות כמו הוספת צומת, קשר, העברה בין אזורים, עדכון או מחיקה מוצגות כרשימה עם תיבות סימון. כל החלה אפשר לבטל ב־↶ (או Ctrl+Z).
- **✨ סדר הכל**: ה-AI עובר על כל הצמתים בקבוצות, מציע תיקוני אזור/סוג וקשרים חסרים, ואתה מאשר.
- **ייצוא לתוכנות עיצוב ועריכה**:
  - **PSD** ל-Photoshop: שכבה לכל אזור (עם שם בעברית), שכבת קשרים, מוח ורקע.
  - **SVG בשכבות** ל-Canva, Illustrator, Figma, Inkscape.
  - **PNG** ברזולוציה כפולה, **JSON** לגיבוי וייבוא.
  - ה-AI יכול לבקש ייצוא בעצמו ("ייצא ל-Photoshop"), גם כן באישור.

## חיבור ל-AI

⚙ בהגדרות: Anthropic (ברירת מחדל `claude-sonnet-5-5`), OpenAI, Mistral, Gemini, OpenRouter או כל שרת תואם OpenAI. הקריאות יוצאות ישירות מהדפדפן אל הספק. המפתח נשמר רק בדפדפן ולא נכלל בייצוא או בגיבוי.

כשאתר חוסם קריאה מהדפדפן (CORS), האפליקציה מנסה קורא חיצוני (`r.jina.ai`) שמקבל את כתובת האתר. אפשר לכבות בהגדרות.

## בנייה מחדש

המקור ב־`src/`. `python3 build.py` מדביק הכול לתוך `index.html`.

| קובץ | תפקיד |
|---|---|
| `regions.js` | צורת המוח, 12 האזורים וסוגי הצמתים |
| `store.js` | מצב הגרף, שמירה, ביטול |
| `layout.js` | פריסה לפי אזורים |
| `ai.js` | חיבור לספקים והפרומפטים |
| `ingest.js` | קריאת קבצים וקישורים, חילוץ ומיזוג |
| `view.js` | ציור SVG, זום וגרירה, צביעת הפעילות |
| `exportx.js` | SVG / PNG / PSD / JSON |
| `app.js` | ממשק, פקודות AI, הצעות |

זה כלי לארגון ידע אישי ולהתבוננות, לא כלי רפואי. הסידור לפי אזורי מוח הוא סימבולי.
