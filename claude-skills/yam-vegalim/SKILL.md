# ים וגלים ריאליסטיים

שלושה חלקים שחייבים להסכים ביניהם: **מה שמצויר** (שיידר), **מה שהפיזיקה יודעת** (אותה נוסחה ב־JS), **ומה שעף באוויר** (חלקיקים).

## 1. גלים בים הפתוח
- סכום של 4 גלי Gerstner (כיוון, אורך גל, תלילות, גובה). הגלים הארוכים מתגבהים במים עמוקים, והקצרים (אדוות) כמעט לא.
- **מפת עומק אחת לכל העולם** (טקסטורה של גובה הקרקעית). ממנה יודעים איפה רדוד, מה צבע המים, ואיפה החוף.
- נורמל אנליטי מהגלים, ועליו שתי מפות נורמל שזזות לפרטים קטנים. הפרטים נחלשים עם המרחק.
- **הגלים מוצגים כך שהם דועכים במרחק**, אחרת רואים רעש על קו האופק.

## 2. גלי חוף שנשברים
הטריק: הפאזה של הגל תלויה ב**שורש העומק**. קווי עומק שווים מקבילים לחוף, ולכן הגלים תמיד מתקדמים לכיוון החוף ומאטים כשהמים נעשים רדודים, בכל חוף ובכל כיוון, בלי לדעת לאן החוף פונה.
```glsl
float surfPhase(vec2 p, float d) { return fract(sqrt(d) * 0.75 + uTime * 0.11 + 0.35 * sin(p.x * 0.011 + p.y * 0.007)); }
float surfAmp(vec2 p, float d) {
  float shoal = 1.0 - smoothstep(2.0, 10.0, d);      // מתגבה ככל שרדוד
  float broken = 1.0 - smoothstep(0.35, 2.2, d);     // אחרי השבירה: נמוך יותר
  return uWaveAmp * 0.95 * shoal * (1.0 - 0.7 * broken) * smoothstep(0.02, 0.6, d);
}
// צורה: חזית תלולה (u < 0.2), גב מתון
float surfH(vec2 p, float d) { float u = surfPhase(p, d);
  return surfAmp(p, d) * (u < 0.2 ? smoothstep(0.0, 0.2, u) : pow(1.0 - (u - 0.2) / 0.8, 1.8)); }
```
- הגובה נוסף בשיידר הקודקודים. הנורמל מחושב בהפרשים סופיים: עוד שתי דגימות של הקרקעית ושל `surfH`.
- **קצף:** שפה לבנה בפסגה בעומק של כ־2 מטרים (lip), קיר קצף שרץ על החול מאחורי הפסגה (bore), ותחרה שנשארת עד הגל הבא (lace).
- **קבועים משותפים:** הערכים יושבים באובייקט JS אחד, ונכתבים לתוך ה־GLSL בתבנית, עם `toFixed(1)` למספרים שלמים (ב־GLSL `10` הוא int ולא float).

## 3. אותה נוסחה ב־JS
```js
export function waveAt(x, z, time, amp, out, depth) { /* סכום Gerstner */ if (depth < 10) out.y += surfAt(x, z, time, amp, depth).h; }
```
- סירות, מצופים, בעלי חיים ובדיקת "המצלמה מתחת למים" משתמשים בה, כדי שהכלים יצופו בדיוק על המים שרואים.

## 4. רעש לקצף: מלכודת
**בתמונת נורמלים הערוץ הכחול כמעט קבוע (בערך 0.99).** רעש שנלקח ממנו לא משתנה, ולכן הקצף נראה כמו צבע חלק. משתמשים בערוצים האדום והירוק, ומנרמלים אותם:
```glsl
float foamNoise(vec2 uv) { vec2 c = texture2D(tNormal, uv).rg; return (c.x + c.y - 1.0) * 15.0; } // פיזור בסביבות 1
```
**לפני שמכוונים ספים, מודדים את ערכי הטקסטורה** (אחוזונים) עם קריאה מה־GPU.

## 5. רסס בצבע של מים
- חלקיקים שמוארים בצבע השמש יוצאים **אדומים בשקיעה**. מים לבנים מפזרים אור הרבה פעמים, ולכן כמעט לא שומרים על צבע השמש:
```js
L.copy(lit).multiplyScalar(gain);
L.lerp(grey.setScalar(L.r * 0.2126 + L.g * 0.7152 + L.b * 0.0722), 0.82); // להוריד רוויה
L.multiply(tint); // גוון קל של ים: (0.88, 0.97, 1.0)
```
- טקסטורת רסס: גוף ערפילי קרוע עם הרבה טיפות קטנות. לא עיגולים חדים, שנראים כמו נקודות פולקה.
- מקורות רסס: חרטום הסירה (יותר במהירות ובפנייה חדה), זנב מהמנוע, נחיתה אחרי קפיצה, **וגלים שנשברים ליד המצלמה**: דוגמים נקודות אקראיות סביב המצלמה, ובכל נקודה בעומק 1.3–3.2 מטר כשהפסגה עוברת, זורקים רסס למעלה ולכיוון החוף (לפי שיפוע הקרקעית).

## 6. שובל וקצף על המים
- **אין חומר לא מואר.** שובל שצויר בלבן קבוע זהר בערב ובלילה, כי הצנרת היא HDR עם חשיפה משתנה. מעבירים לו את אותה תאורה של הרסס בכל פריים.
- שוברים את השובל לכתמים ופסים שזזים אחורה, ודועכים מאחור.

## 7. בדיקה
- מצלמה קבועה מול חוף, כמה צילומים בהפרש של כשנייה, כדי לראות גל נשבר.
- מירוץ סירות **באי של השקיעה ובאי של הלילה**, לא רק בצהריים.
- השוואה של `waveAt` מול מה שמצויר: הסירה לא טובעת ולא מרחפת.

## איך לעשות יותר טוב בפעם הבאה
- שובל רטוב וכהה על החול אחרי כל גל, וקצף שנשאר על החוף.
- השתקפות אמיתית של בניינים והרים (planar reflection או SSR) במקום השתקפות שמיים בלבד.
- טיפות על עדשת המצלמה בנסיעה מהירה בסירה.
- גלים מסביב לעמודי גשר, סלעים וסירות.
- צליל של גלים שמשתנה לפי הקרבה לחוף הנשבר.
- ים שמשתנה עם מזג האוויר: סערה עם כתרי קצף רבים, או ים שקט כמו מראה.
