# מצב צילום

## שלב 1: צילום בסיסי (עובד בשימוטרון)
```js
photo() {
  engine.pipeline.render(0);                         // פריים טרי
  canvas.toBlob((blob) => savePhoto(blob), 'image/png'); // לקרוא באותה משימה
  ui.flash(); audio.ui('click');
}
```
- **למה באותה משימה:** ב־WebGL עם `preserveDrawingBuffer: false`, התמונה ב־canvas נמחקת אחרי שהיא מוצגת. מציירים וקוראים מיד. לא מדליקים `preserveDrawingBuffer`, כי זה מאט כל פריים.
- **התמונה נקייה מעצמה:** לוח המחוונים והכפתורים הם אלמנטים של הדף, לא חלק מה־canvas.
- מקש F (לא P, שהוא עצירה) וכפתור מצלמה. שני כפתורים לא יקבלו אותו סמל: מצלמה לצילום, מצלמת וידאו להחלפת זווית.
- שם קובץ עם תאריך ושעה: `shimotron-2026-09-25_08-31-23.png`.

## שלב 2: שמירה למחשב
- **מקובץ מקומי או מאתר:** `<a download>` עם `URL.createObjectURL(blob)`, לחיצה, הסרה, ושחרור ה־URL אחרי כמה שניות. הודעה: "התמונה נשמרה בתיקיית ההורדות · שם".
- **בתוך הצופה של claude.ai** אסור להוריד ישירות. מבקשים מראש (בטעינה) `window.claude.use('downloads')`, ובצילום:
```js
const host = await this._downloads; // null מחוץ לצופה
if (host) { try { await host.save({ filename, data: blob }); } catch (e) { /* declined / unavailable */ } }
```
  ובפרסום: `capabilities: { downloads: true }`. הצופה שואל את המשתמש, ו"לא" הוא לא שגיאה.
- בדיקה אוטומטית: `page.waitForEvent('download')`, ובדיקה שהקובץ לא ריק. להסתכל על התמונה עצמה.

## שלב 3: מצב צילום מלא (הצעד הבא)
- **עצירת הזמן:** `engine.paused = true`, אבל ממשיכים לצייר. חלקיקים, מים ועננים עוצרים בפוזה.
- **מצלמה חופשית:** WASD ועכבר, או גרירה במגע, עם הגבלת מרחק מהרכב (למשל 30 מטר) ומעל הקרקע.
- **הסתרת הממשק** בכניסה למצב צילום, ורמז קטן בפינה ("F צילום · Esc יציאה").
- **עומק שדה:** לחיצה על נקודה קובעת פוקוס (`focusDistanceAt`), ומחוון לעוצמת הטשטוש.
- **פילטרים:** טבלת צבע (LUT) או מעבר צבע בסוף הצנרת: חמים, קולנועי, שחור־לבן, וינטג׳. מחוונים לחשיפה ולרוויה.
- **מסגרת וחתימה:** לוגו "שימוטרון" ותאריך בפינה (אופציונלי), שמצוירים על canvas דו־ממדי לפני השמירה.

## שלב 4: איכות גבוהה מהמסך
- הצילום מקבל את רזולוציית ה־canvas, שעלולה להיות נמוכה בגלל רזולוציה דינמית. לצילום:
  1. מציירים ל־`WebGLRenderTarget` בגודל פי 2 (או 4K), עם אותה מצלמה ויחס רוחב־גובה.
  2. קוראים עם `readRenderTargetPixels` (שורות הפוכות!), מעתיקים ל־`ImageData` ול־canvas דו־ממדי, ואז `toBlob`.
  3. או משנים זמנית את `setPixelRatio` ואת גודל הצנרת, ומחזירים. זה מקצה מאגרים מחדש, ולכן רק בצילום.
- זהירות מזיכרון בכרטיסים חלשים. להציע "גבוהה" רק ברמות איכות high ו־ultra.

## שלב 5: גלריה
- שומרים תמונות ממוזערות בזיכרון (או ב־IndexedDB, מחוץ לצופה) ומציגים רשת בתפריט. לחיצה מגדילה, ויש כפתורים להורדה חוזרת ולמחיקה.
- אפשרות "שתף": `navigator.share` עם קובץ, בנייד.

## איך לעשות יותר טוב בפעם הבאה
- הקלטת וידאו קצר (`MediaRecorder` על `canvas.captureStream()`) של 10 השניות האחרונות.
- הילוך חוזר שממנו מצלמים, עם מצלמות טלוויזיה.
- צילום פנורמה או 360.
- פוזות לנהג ולרכב (דלתות פתוחות, אורות דולקים) לפני הצילום.
