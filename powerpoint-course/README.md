# קורס PowerPoint מלא — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת.

## מה יש בפנים

- **3 שלבים · 22 שיעורים**: מתחילים (ממשק, שקופיות, טקסט, תמונות, שמירה) → בינוני (Slide Master, ערכות נושא, אנימציות, מעברים, SmartArt, טבלאות/גרפים, מדיה, יישור) → מקצוענים (קיצורי מקלדת, תבניות `.potx`, מאקרו/VBA, שיתוף פעולה, Presenter View/Morph, ייצוא מתקדם, נגישות, עקרונות עיצוב).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר.
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open powerpoint-course/index.html   # macOS
xdg-open powerpoint-course/index.html   # Linux
```
