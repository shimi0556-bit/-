# קורס Gmail מלא — ממתחילים ועד מקצוענים

אתר לימוד אינטראקטיבי בעברית (RTL), עמוד `index.html` אחד ללא תלות בבנייה (build) או בחיבור לרשת. אותה תבנית קורס כמו [`../powerpoint-course/`](../powerpoint-course) ו-[`../excel-course/`](../excel-course).

## מה יש בפנים

- **3 שלבים · 21 שיעורים**: מתחילים (ממשק, כתיבה ומענה, צירופים וחתימה, ניהול בסיסי, חיפוש, זיהוי פישינג) → בינוני (תוויות, מסננים אוטומטיים, אופרטורי חיפוש מתקדמים, כרטיסיות תיבת הדואר, אינטגרציית Calendar/Drive/Meet, אנשי קשר, תזמון/Snooze) → מקצוענים (קיצורי מקלדת, כתובות משניות, אבטחה מתקדמת (2FA/Confidential Mode), תבניות, אוטומציה עם Apps Script, Google Workspace, IMAP/POP, עקרונות ניהול תיבה מקצועית — כולל השוואה קצרה מול Outlook.com ו-Yahoo Mail).
- שאלת תרגול בסוף כל שיעור עם משוב מיידי.
- מעקב התקדמות נשמר בדפדפן (`localStorage`) — סימון "הושלם" לכל שיעור ופס התקדמות בתפריט.
- דף קיצורי מקלדת מרוכז, מותאם להדפסה.
- מבחן מסכם על כל החומר.
- תעודת סיום (עם שם אישי) שנפתחת אחרי השלמת כל השיעורים, ניתנת להדפסה/שמירה כ-PDF.
- תפריט צד עם חיפוש, ותמיכה מלאה במובייל.

## איך מריצים

פתחו את `index.html` ישירות בדפדפן — אין תלות בהתקנה, שרת או חיבור לאינטרנט.

```
open gmail-course/index.html   # macOS
xdg-open gmail-course/index.html   # Linux
```
