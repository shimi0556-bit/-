# Screencast Notes

תוסף כרום (Manifest V3) להקלטת מסך וצילומי מסך, עם פתק הערות צף שמופיע
בכל דף. בפתק אפשר לפתוח כמה **לשוניות הערות** (בדומה ללשוניות שבארטיפקט),
לכתוב בכל אחת, ולעבור ביניהן גם באמצע הקלטה. כל לשונית נשמרת **לפי הדף
(URL) שבו נכתבה** — כשחוזרים לאותו דף הפתק מופיע מחדש באותה פינה קבועה
עם אותן הלשוניות וההערות.

## התקנה

1. פתח `chrome://extensions`.
2. הפעל Developer mode (בפינה הימנית-עליונה).
3. "Load unpacked" → בחר את התיקייה הזו (`screencast-notes/`).

## שימוש

- **הקלטת מסך** — מהפתק הצף (בפינה שמאלית-תחתונה של כל דף) או מהפופאפ של
  התוסף: "⏺ הקלט מסך" פותח את בורר ההקלטה המובנה של כרום (מסך מלא / חלון
  / לשונית). עצירה דרך אותו כפתור. הקובץ (`.webm`) נשמר בתיקיית
  ההורדות תחת `screencast-notes/`.
- **צילום מסך** — "📷 צלם מסך" מצלם את הלשונית הגלויה כרגע ושומר PNG
  בהורדות.
- **הערות ולשוניות** — כפתור "+" בפתק פותח לשונית הערות חדשה; לחיצה על
  לשונית עוברת אליה; דאבל-קליק משנה שם; ה-✕ מוחק (כשיש יותר מלשונית
  אחת). הטקסט נשמר אוטומטית תוך כדי כתיבה.
- **חזרה לדף** — מכיוון שההערות נשמרות לפי כתובת הדף המדויקת, אם חוזרים
  לאותו URL (גם בלשונית/חלון אחר של כרום) הפתק יציג את אותן לשוניות
  והערות.
- כיווץ/הרחבה של הפתק עם הכפתור "—" בכותרת.

## איך זה עובד מתחת למכסה

- `background.js` (service worker) מנהל את מחזור החיים של ההקלטה וצילומי
  המסך, ומשתמש ב-`chrome.desktopCapture` לבחירת מקור הקלטה.
- מאחר ו-service workers ב-MV3 חסרי DOM (אין `getUserMedia`/`MediaRecorder`),
  ההקלטה בפועל רצה במסמך offscreen נסתר (`offscreen.html`/`offscreen.js`)
  שמוקם ומבוטל דרך ה-`offscreen` API.
- `content.js`/`content.css` מזריקים את הפתק הצף לכל דף (`<all_urls>`).
  מצב ההערות נשמר ב-`chrome.storage.local` תחת מפתח ייחודי לכל
  `origin+pathname+search`, כך שכל "דף" שומר את הלשוניות שלו בנפרד, ומסונכרן
  בזמן אמת אם אותו דף פתוח במספר לשוניות כרום.
